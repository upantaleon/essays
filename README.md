# Essays — Dr. Umar Pantaleon Umangay

The essays publication of Dr. Umar Pantaleon Umangay, Consultant, Pantaleon Consulting.
Published with GitHub Pages at https://upantaleon.github.io/essays/

This site replaced the Substack publication (umarumangay1.substack.com) in November 2026.
The essays live here as plain files in this repository, so the archive is never held inside a platform's format.

## Structure

- `index.html` — the essay index. Add one list entry per essay, newest first.
- `essays/<slug>.html` — one self-contained page per essay.
- `style.css` — the shared stylesheet.

## Adding an essay

1. Create `essays/<slug>.html` from an existing essay page (keep the header, footer, and `../style.css` link).
2. Add its entry to the list in `index.html` and to `sitemap.xml`.
